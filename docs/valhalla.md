# Valhalla

Valhalla 是 Reference 内的模型更新评价与性能测试记录区。没有独立的新建词条入口，也不会预先创建或发布模型评测。

1. 打开已有 Reference 词条，在编辑页勾选「同步到 Valhalla」。
2. 点击顶部自动出现的 Valhalla 卡片，编辑独立的评测正文。可使用已有的图片、表格、链接卡片、可复制代码和沙箱演示块。
3. 按模型版本组织更新评价、测试条件、提示词、用时与结果。系统不预填真实性能分数，也不会自动调用外部模型运行基准测试。
4. 保存只保留草稿。点击发布后，Reference 与 Valhalla 的当前内容一起公开，两边顶部自动显示对方的关联卡片。

两侧使用同一个词条 ID、名称、标签、版本和发布状态。Valhalla 正文独立保存；取消同步并发布会隐藏公开入口及评测内容，后台仍保留评测草稿。删除原词条沿用既有站主确认或伙伴审核，同时移除对应评测入口。

## 草稿与恢复

新字段 `documents.valhalla` 与 `revisions.valhalla` 保存 `{enabled, blocks}`。旧客户端保存时省略该字段，会保留既有评测。保存与发布沿用版本冲突检查和发布锁；评测图片只有开启同步并显式发布后才转换为公开路径。禁用同步的公开快照不包含评测正文、图片引用或搜索摘要。

恢复浏览器旧稿只恢复当前侧正文。服务器版本变化时保留最新名称、标签、同步设置及另一侧正文，并在恢复提示中说明；不以旧恢复副本覆盖另一侧的新内容。

## 部署

已有 D1 先检查 `documents` 与 `revisions` 是否包含 `valhalla`。首次升级执行 `server/migrations/0003-valhalla.sql`，再部署 Worker；迁移只新增两个带空默认值的列，不创建词条、不改正文、公开快照或版本。新数据库使用完整 `server/schema.sql`；本机开发适配器自动补齐字段。

路由为 `#/valhalla`、`#/valhalla/<词条 ID>` 与后台对应的 `#/write/valhalla`、`#/write/valhalla/<词条 ID>`。索引复用 A–Z/拼音、标签和搜索，但只收录已勾选词条，正文搜索来自评测内容。公开阅读始终读取已发布快照。
