# 编辑工作台布局稿

三张方案均为内置 image_gen 生成的桌面设计示意，非可操作网页。统一采用用户指定的简洁、类飞书方向：浅色背景、系统中文字体、蓝色操作强调、清楚的多级目录与草稿/发布状态。

- A：`.impeccable/mocks/editor-a.png`。左侧目录，中间编辑区，右侧常驻大纲。适合长篇教程和多层级内容，优先推荐。
- B：`.impeccable/mocks/editor-b.png`。左侧目录，正文居中，大纲按需打开。优先保持连续写作空间。
- C：`.impeccable/mocks/editor-c.png`。最左功能栏、独立文档列表、正文编辑区。适合频繁管理和切换文章，但导航占用更多宽度。

状态：用户已选择 A。每张图的 prompt 与批准状态记录在同名 JSON 中。示例文章、目录与表格只是演示排版，正式内容由站主决定。生成图中的按钮、角色入口、数字及保存状态不得当作已经实现的功能或事实。

## 实现清单

| 稿件元素 | 实现方式与约束 |
| --- | --- |
| 左侧目录与功能导航 | 语义化按钮、树形嵌套结构、Lucide 图标；约 248px 宽，浅灰背景，选中项浅蓝 |
| 顶部路径、保存状态、预览与发布 | HTML/CSS 与真实状态；发布按钮蓝色，失败不能显示已保存 |
| 文档内容与排版控件 | BlockNote 社区组件；白色编辑区、系统字体，图片和表格可真实编辑 |
| 右侧大纲 | 从文档标题块提取，点击滚动定位；约 190px 宽 |
| 正文图像区域 | 创作者上传的内容，不把示意稿占位图变成网站装饰素材 |
| 草稿与阅读切换 | 发布版本独立保存；本地演示与真实 GitHub 登录明确区分 |
