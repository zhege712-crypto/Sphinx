# 词条标签、搜索与返回（2026-10-17）

Reference 词条可添加最多12个标签，每个1–32字符，支持输入或选择已有标签。标签随正文保存到草稿与历史，只有显式发布后才进入公开快照；旧客户端不发送标签时保留原值。作者未提交的标签输入在离开编辑器前一并校验、提交，失败则留在原页。未提交输入也进入本机恢复副本。

搜索统一覆盖名称、标签、正文，支持空格分隔的多关键词、全半角和大小写规范化、名称与标签拼音及拼音首字母。名称匹配优先，然后标签、拼音与正文。Reference 搜索显示相关标签、计数、命中高亮和片段，支持标签与字母交叉筛选；侧栏搜索同时包含指南、目录与 Reference，支持清空、Escape、方向下键进入结果和 Enter 打开首项。词汇链接选择器复用同一搜索规则。

普通创作文档使用 `#/write/documents/<id>`，管理页面和词条使用独立路由。浏览器前进/后退能识别具体目标。站内返回按钮优先回到来源页；直接打开时回到词条索引或全部文档，不依赖可能指向外站的浏览器历史。离开编辑器前等待保存；校验或保存失败时保留编辑页与输入。公开词条同时提供索引入口；从文章词汇跳入词条后可以回到原文章。

Reference 在当前浏览器会话保存搜索、标签、字母、滚动位置与最后打开的词条，返回后恢复焦点。读者与作者筛选分开。文章和编辑页按文档记住滚动位置。存储不可用时仍可访问和保存。

数据库：新建库使用最新 `server/schema.sql`。已有库在新 Worker 部署前只执行一次 `server/migrations/0001-reference-tags.sql`，给 documents/revisions 添加默认 `[]` 的 tags 列；不要对已经包含 tags 的新库再次执行。迁移不改正文、发布快照、版本或修改时间。本地演示启动时按实际列自动补齐。

验证使用独立的本地测试词条；未修改、补标签或发布生产内容。已检查联合搜索、拼音、标签过滤、浏览器返回、失败保存保护、来源文章返回及手机索引滚动恢复。真实生产数据的历史标签在作者新增和发布前保持为空。
