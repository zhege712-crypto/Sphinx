# 手机端适配（2026-10-17）

保持桌面三栏文档桌面风格，新增手机与平板布局。源文件为 `src/responsive.css`，媒体查询状态由 `src/useMediaQuery.js` 统一监听。

- ≤900px：导航改为原生模态抽屉，包含关闭按钮、遮罩、Escape 关闭和焦点恢复。打开时主页面由浏览器保持不可操作；选择页面后收起。Ctrl/Cmd+K 可以打开导航并聚焦搜索。
- ≤1100px：本文目录移至正文上方，默认收起；选择标题后恢复焦点到目录入口、收起并定位。更宽屏幕保留原来的右侧大纲。
- 手机阅读与编辑正文为16px，表单输入为16px以避免 iOS 输入自动放大，主要触摸按钮至少44px。手机标题28px。
- 手机编辑页将标题与保存/预览/发布操作分为两行。排版与插入工具栏各自在自身区域横向滚动；所有原有插入工具仍可访问。
- Reference 搜索占可用宽度、字母索引换行、词条列表为单列。拼音索引规则不变。
- 图片按内容宽度缩放；图文并排在手机上展示为先图后文，不改变已保存内容。宽表格与代码块在自身区域滚动，管理表格包含有名称、可键盘聚焦的滚动容器。
- 弹窗限制在动态视口内并可滚动；支持安全区域边距和底部提示。

验证：浏览器视口320×740、390×844、768×1024、1024×768、1536×960；另用320×420检查低高度弹窗。检查阅读、Reference、登录、编辑、管理表格、抽屉开关与焦点、搜索快捷键、大纲跳转、本地草稿自动保存、表格插入与预览。测试稿只存于本地演示，不发布到生产。31项现有测试通过，构建通过。尚未在真实 iOS/Android 设备上验收系统键盘与触摸选区。
