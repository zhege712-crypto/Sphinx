# 安全边界与运行约束

## 2026-10-18 安全检查与加固

- 公开阅读站不再展示伙伴工作台或编辑词条入口。站主登录工作台后，在“协作成员”添加账号并复制入口。工作台网址和源码仍可被发现；入口隐藏不是访问控制，服务端继续按 GitHub 稳定 ID、有效会话及成员状态授权。
- `/api/assets/:id` 在查询图片是否存在前先鉴权并计入用户读取限流；未登录统一返回 401，不泄露图片存在性。此私有接口始终禁止缓存。仅已发布图片可通过 `/assets/:id.ext` 公开读取。
- 工作台成功和错误响应统一提供 CSP、防嵌入、禁止 MIME 猜测、同源资源策略及禁用摄像头/麦克风等安全头。生产构建也内置 CSP 和不发送 Referrer 的策略，覆盖 GitHub Pages 阅读站；Pages 无法通过 HTML meta 提供 `frame-ancestors` 和 HSTS 等 HTTP 响应头。Mantine/BlockNote 需要内联样式，脚本仍限制为本站来源。
- 本地演示身份只允许显式开启且请求地址和配置地址均为相同本机 HTTP 主机；生产域名即使误设演示标志也不能使用演示登录。登录端点限制请求方法、正式 OAuth 来源和返回身份格式；普通 JSON 写入接口拒绝非 JSON 或非对象请求。
- 匿名和伙伴的会话响应不再公开发布配置状态；伙伴直接访问成员管理、发布记录页面会返回工作台，服务端仍单独拒绝相应 API。退出成功时清空界面中的私有列表、当前文档和搜索状态；为避免丢稿，不擅自删除未保存内容的标签页恢复副本，使用共享电脑仍需关闭标签页。
- GitHub Pages 构建 Action 固定为已核验的官方提交 SHA，checkout 不保留仓库凭据。生产依赖审计未发现已收录漏洞；已跟踪源码的已知凭据格式扫描未命中。这些检查不等于完整渗透测试或历史仓库密钥审计。
- 本次 42 项自动测试通过，覆盖未受邀 OAuth、过期/伪造/撤销会话、跨站写入、角色边界、图片公开边界、限流与安全头。独立本机数据库的生产构建浏览器验证确认正文/表格/保存、伙伴入口复制和越权路由正常，控制台未出现 CSP 错误。未用正式草稿做测试；真实 GitHub 授权和发布流程沿用既有配置。

## 现有权限与数据边界

- 项目介绍使用固定 ID 的普通文档；仅站主可初始化，重复初始化不覆盖草稿或恢复已归档内容。后续编辑/历史/发布沿用受邀伙伴的内容权限。公开关于页只读取发布快照，静态联系方式由站主明确提供。新增初始化与草稿边界测试后共 43 项测试通过。

- 所有伙伴管理全部文章、目录和图片。编辑权限意味着可以阅读全部共享草稿；不是按文章隔离的私密空间。
- 站主权限在服务端以稳定 GitHub ID 判定。前端隐藏按钮只是界面优化，API 仍单独校验角色。
- 登录 cookie 为随机 opaque token，服务端仅保存 SHA-256 哈希；生产 HttpOnly、Secure、SameSite=Lax，有效期 8 小时。OAuth state 有效 10 分钟且单次使用。登录 token 不落到前端存储。
- 修改 API 校验同源 Origin 与会话 CSRF token，按用户区分读取/写入限流。私有响应不缓存。
- 正文重建白名单结构，React 转义文本；不保存任意 HTML，链接限制 http/https/mailto，禁止带用户凭据的 URL。图片只接受站内受控资源，排除 SVG。
- 网站卡片 `linkCard` 仅保存标题和 http/https 网址，拒绝脚本、data、mailto 及含账号密码的地址；不抓取外部网页元数据，避免任意服务端 URL 请求。编辑器对未完成的网址显示提示，发布/离开前要求修正。
- Reference 词条与文章共用服务端权限、版本历史、私有草稿及明确发布边界。初始资料迁移仅站主可调用，固定 ID、幂等写入；只有未编辑且与既有公开模板完全相符的初稿会在迁移时发布，不会发布或覆盖用户的改稿。
- 每张图片最多 5 MiB，单篇发布最多 20 张、合计 15 MiB；上传按伙伴每日 100 张/100 MiB 限额。格式依据文件签名，不能代替病毒扫描与完整解码检查。
- 草稿图片分块保存在独立 D1 数据库中，首版总图片预算 256 MiB。上传先原子预留容量，再事务写入分块，失败会释放预留；读取校验分块完整性。文章首次发布后，其引用图片成为公开内容；后续移出文章不等于撤回已公开的图片。公开仓库与浏览器缓存可能持有历史副本。
- 草稿保存使用版本号 compare-and-swap；冲突不自动覆盖，编辑者可导出副本和重新加载。无实时多人合编，首版让各自窗口编辑，保存时识别冲突。
- 保存前保留旧稿到 revisions，界面显示最近 50 条。浏览器在当前标签页 sessionStorage 保留未保存内容副本，仅用于刷新恢复，不存 cookie 或发布凭证。共享电脑应退出并关闭标签页。
- 删除为工作台软归档和公开目录移除，不承诺擦除 Git 历史、缓存或已传播图片。所有删除都需要站主批准。
- 审核申请记录当前目录/版本快照，变化后须重新提交。发布期间阻止内容写入，远程提交结果不明时保留持久作业，由站主恢复状态后继续。
- 单个公开目录首版容量约 1.4 MB JSON。历史、无引用私有图片、备份与配额需由运营侧监控；首版不提供自动永久清理，避免误删。发布使用集合更新，避免审核批量文档与公开多张图片时耗尽 D1 单次调用查询额度。
- Cloudflare 后端配置与真实 OAuth/Pages 端到端验证需在部署环境完成。本地测试不能证明生产配置无误。

## 后续扩展

文章存储统一使用 BlockNote JSON，可后续接 Yjs 协作服务；当前版本号和快照接口保留兼容余地。Yjs 服务、并发权限、实时光标和在线人数尚未实现。

文字链接只额外允许严格匹配 `#/reference/<UUID>` 的站内词条地址；其他相对地址和任意站内管理路由仍拒绝。站外延续 http/https/mailto 协议白名单及禁止网址内用户名密码；新词汇链接表单只接受 http/https。阅读页的站外网页链接以 noopener/noreferrer 在新标签页打开。词条存在不代表已公开，链接本身不会授予私有草稿读取权限。
