# 阅读体验检查 · 2026-10-23

本次沿用现有文档布局、三色主题、作者正文与公开状态，检查指南长文、Reference 图文和表格、章节目录及网络异常路径。

## 发现与修复

- 公开目录刷新失败时，原逻辑用空结果重新选择文章，导致左侧还有目录而正文显示“指南正在准备中”。重试只更新目录，也不会重新选择原文章。现在直接用当前 URL 和最近成功加载的公开目录解析文章，失败不清空正文，重试成功即恢复。
- 初次加载、加载失败与失效文章链接分别显示明确状态，只有真正没有指南的首页才显示准备中的提示。重复请求按序号处理，较旧响应不会覆盖较新的目录。
- 右侧目录原本固定高亮第一项，现在随正文滚动标识当前章节，并提供 `aria-current="location"`。手机选择章节后仍收起目录并恢复焦点；正文标题保留 24px 的跳转留白。
- 深色模式的目录错误提示改用浅红色，避免原有暗红色在深色背景下难以阅读；手机上的错误文字和重试按钮可以换行。
- Pages 目录请求使用 `no-cache` 进行缓存重新验证，仍需取得最新公开状态，不使用持久化的旧目录兜底。

## 验证证据

- 94 项 Node 测试通过，包括新增的 URL 解析、丢失条目、重试后选择及 Reference / Valhalla 隔离回归测试。
- 生产构建、运行时安全下限、依赖锁文件检查、历史与构建产物凭据扫描通过。
- 隔离本机服务模拟首次 503、2.5 秒延迟，以及成功加载后切换文章时再次 503；验证加载提示、重试恢复、保留正文、目录选中状态和章节跳转。
- Edge 中检查白色、深色、护眼主题；320 / 390 / 768 / 1280 像素宽度。正文和页面没有横向溢出；320px 下 DeepSeek 的宽表格只在表格容器内滚动，文中图标正常加载。检查桌面与手机的目录展开、跳转落点及当前章节颜色。
- Impeccable 机械扫描仅给出字号与既有错误颜色的建议，字号已沿用 27px 标题层级；错误颜色沿用现有浅色语义并增加深色适配。没有严重缺陷报告。
